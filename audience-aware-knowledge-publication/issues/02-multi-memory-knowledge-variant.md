# Define multi-Memory Knowledge Variant identity and synthesis

Type: grilling
Status: open
Labels: wayfinder:grilling
Blocked by: 01, 06

## Question

When several related Memories are relevant to an Audience, when should they become one Knowledge Variant versus several variants linked by Areas or Relations?

Decide the unit of synthesis, stable identity across source updates and re-curation, topic boundaries, and split/merge/retire behavior. Cover a document supported by sources from multiple Realms, a Memory that becomes irrelevant, and two sources that overlap or contradict one another. The result must keep Knowledge Variant content subordinate to canonical Artifacts and define the contributing-source set used for authorization and invalidation.
