# 06: Manage Realms and Controlled Tags

**What to build:** An administrator manages Realm attachment and classification vocabulary, with the detailed tag guidance and confidence controls needed for consistent Intake review.

**Blocked by:** 01 Browse authorized Publications locally.

**Status:** ready-for-agent

- [ ] An administrator can create, attach, and detach a Realm using existing application operations and receives clear outcome/error feedback.
- [ ] Detachment confirmation names affected Audience access and Publication/rebuild consequences.
- [ ] Controlled Tag labels remain immutable; edits update wording and handling guidance for the existing tag identity.
- [ ] Tag descriptions have a full-width editor below the tag name and confidence thresholds.
- [ ] Separate auto-accept and locked-review thresholds are editable, validated in range, and locked-review is no lower than auto-accept.
- [ ] Strong contrary evidence against a human-locked tag is described as a review event and does not silently change the locked classification.
- [ ] Tag deletion requires confirmation describing classification, Audience-policy, and rebuild effects.
- [ ] Provider credentials are not presented as connected or configurable; their plugin/Installation configuration remains a documented gap.
- [ ] HTTP integration tests verify attachment/configuration effects, validation, and consequential deletion behavior.
